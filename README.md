# dsh-web-search-insights

DeepSeek Harness（DSH）插件：把 Agent 的联网使用情况（`web_search` / `web_fetch`）做成「可审计的日志 + 可回看的引用与抓取统计」。

- **审计日志**：记录每次搜索的关键词与结果、每次抓取的 URL 与 HTTP 结果，正文永不入日志；
- **会话统计**：按轮次/会话汇总引用来源、返回来源与被抓取页面；
- **界面**：回答末尾入口、右侧栏「搜索记录」面板、左侧菜单与右侧栏的「搜索统计」（按天统计、关键词分布、词云），以及会话顶部的「快速搜索」视图。

## 依赖要求

- DSH `>=0.2.1-rc.2 <0.3.0`；
- Node.js `^22.19.0 || >=24.0.0`；
- 快速搜索与搜索统计依赖宿主提供同源 HTTP 路由（web profile 自带）。

## 安装

### 方式 A：从 npm 安装（推荐）

```bash
dsh plugin --profile web add @ypingcn/dsh-web-search-insights
```

### 方式 B：从 GitHub 安装

```bash
dsh plugin --profile web add github:ypingcn/dsh-web-search-insights
```

### 方式 C：本地 link 安装（开发调试）

```bash
dsh plugin --profile web add link:/path/to/dsh-web-search-insights
```

## 配置项

插件管理页打开「搜索溯源」后，详情页里会直接出现配置表单。

- 「搜索统计面板」默认开启，同时控制左侧菜单入口与右侧栏标签页；关闭后两处入口都会消失，已有日志不受影响。

## 搜索统计

左侧菜单栏的「搜索统计」会把主区域切到统计页，右侧栏的同名标签页是同一视图的紧凑版；两处入口只读取本机审计日志（活动文件 + 轮转文件），不新增写入：

- **汇总指标**：搜索次数（一次 `web_search` 调用计 1 次，多关键词也只算 1 次）、关键词总数、涉及会话数、失败次数（记录 `ok: false` 的调用）；
- **逐日统计**：按天汇总搜索次数、关键词总数、涉及会话数与失败数，柱状图展示趋势，可展开「按天明细」表格；窗口内没有记录的日期补 0；
- **关键词分布**：窗口内 Top 10/20/50，支持整句（默认，按 `queries` 原样计数）与简单分词两种口径，均可本地过滤；
- **词云**：与「搜索次数」「关键词分布」并列的独立标签页，按分词结果生成，字号随出现次数缩放；点击词汇会回填过滤条件并切到「关键词分布」；
- **标签切换**：搜索次数、关键词分布、词云以三个标签页呈现，同一时间只显示一个，不再上下堆叠；
- **时区**：按浏览器 IANA 时区分日，跨 UTC 日界与夏令时不会重复或漏掉日期；
- **范围**：最近 7/30/90 天；历史范围受日志轮转与保留策略限制，页面会提示最早可回溯日期；
- **刷新**：右上角「刷新」会跳过宿主侧的结果缓存重新统计，底部显示更新时间与统计所用时区；
- **不包含**：快速搜索（该功能按设计不写审计日志）与 `web_fetch`。

统计面板的开关见上文「配置项」：关闭「搜索统计面板」后，左侧菜单入口与右侧栏标签页会一起消失，已有日志不受影响。
